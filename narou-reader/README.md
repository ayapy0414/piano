# なろう系リーダー

Web小説を取り込んで、手元で縦書きで読めるリーダーです。
パソコン上で小さなサーバーを動かし、ブラウザで開いて使います。

## できること

- **いくつかのサイトから本文と画像を取り込む**
  - 小説家になろう（ノクターン・ムーンライトも含む）
  - カクヨム
  - ハーメルン
  - 青空文庫（図書カードのURLでも本文のURLでも取り込めます）
  - その他のWebページ・画像のURL（本文を自動で探して1話として取り込みます）
  - 挿絵や外字の画像はダウンロードして手元に保存します
- **縦書きで読む**（横書きにも切り替えられます）
  - ルビ、傍点、2桁の数字や「!?」の縦中横に対応
  - マウスホイール、←→キー、スペースキー、画面の左右タップでページ送り
  - 文字サイズ・行間・書体（明朝/ゴシック）・背景（白/紙/黒/自動）を変更可能
  - 読んでいた話と位置を覚えていて「続きから読む」で戻れます
- **元のページへ戻れる**
  - 本棚、目次、閲覧画面、ファイル一覧のそれぞれに、元のサイトへのリンクがあります
- **取り込んだファイルの一覧**
  - 「ファイル一覧」画面で、保存した目次・本文・画像を、作品や種類で絞り込んで確認できます
  - それぞれのファイルに元のURLへのリンクが付いています

## 使い方

Node.js 18 以上が必要です。

```sh
cd narou-reader
npm install
npm start
```

ブラウザで <http://127.0.0.1:8787/> を開き、作品のURL（目次のURLでも、ある話のURLでも可）を貼り付けて「取り込む」を押します。

- 取り込んだ時点では目次だけを保存し、本文は開いた話から順に保存します（次の話は自動で先読みします）。
- 「全話の本文と画像もまとめて保存する」にチェックを入れるか、目次画面の「未保存の◯話を保存」で、全話をまとめて保存できます。
- 「目次を更新」で、新しく投稿された話を追加できます。

### 設定（環境変数）

| 変数 | 既定値 | 内容 |
| --- | --- | --- |
| `PORT` | `8787` | 待ち受けるポート番号 |
| `HOST` | `127.0.0.1` | 待ち受けるアドレス。スマホなど他の端末から読むときは `0.0.0.0` |
| `NAROU_READER_DATA` | `./data` | 取り込んだファイルの保存先 |
| `NAROU_READER_INTERVAL_MS` | `1000` | 同じサイトへアクセスする間隔（ミリ秒） |
| `NAROU_READER_UA` | ブラウザ風のUA | 取得時のUser-Agent |

## 保存の仕組み

```
data/works/<作品ID>/
  work.json          作品情報・目次・読書位置・画像の元URL
  episodes/<n>.json  各話の本文（前書き・本文・後書き）
  images/<hash>.png  本文中の画像
```

本文のHTMLは表示に必要なタグ（段落・ルビ・画像など）だけを残して無害化してから保存します。

## 注意

- 個人で読むためのツールです。取り込んだ作品の著作権は各作者にあります。再配布はしないでください。
- 相手のサーバーに負担をかけないよう、同じサイトへは1秒以上の間隔を空けてアクセスします。
- 各サイトのページ構造が変わると取り込めなくなることがあります。その場合は `lib/sites/` の該当ファイルを修正してください。

## 開発

```sh
npm test
```

サイトごとの解析は `lib/sites/` にあります。新しいサイトに対応するには、`match` / `fetchWork` / `fetchEpisode` を持つファイルを追加し、`lib/sites/index.js` に登録します。
